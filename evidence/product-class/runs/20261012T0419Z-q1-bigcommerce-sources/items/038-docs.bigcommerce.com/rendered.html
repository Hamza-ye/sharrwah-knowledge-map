# Redirects

Manage 301 redirects for one or more storefronts powered by a single BigCommerce backend. For a list of redirects that are not allowed, see the [301 Redirects FAQ](https://support.bigcommerce.com/s/article/301-Redirects#faq) in our Help Center.

> **Note**
>
> When a storefront URL changes, BigCommerce creates 301 redirects only for storefront channels, meaning any [channel](/developer/api-reference/rest/admin/management/channels) with a `type` of `storefront`. This includes Stencil (`bigcommerce`), Catalyst, Next, WordPress, and custom storefront channels.
>
> * **Non-storefront channels.** Channels with other types, such as marketplace and marketing channels, don't get 301 redirects because they don't serve storefront pages.
> * **Existing redirects.** Redirects already created for non-storefront channels stay in place.
