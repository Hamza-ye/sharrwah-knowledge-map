# Corrections to Stage 1's records

**What this file is:** an input to the work. It lists what was found wrong, or easily overstated, in Stage 1's records after G1, each with what the record should say and the source to read. The record links open Stage 1's files as they stood at G1, unchanged since. Phase D reads it before it uses any of these ids, and the records themselves are not edited, because `method/build_yemen_cases.py` builds them.

- **A correction:** the record says more, or other, than its source.
- **A caution:** the record holds against its quotes, but is easily overstated.

The checks that found these were made on 24 October 2026, during work that is now history. Each row links to its finding. Every source link opens the held copy at the commit the check read.
