# Get Country

GET https://api.bigcommerce.com/stores/{store_hash}/v2/countries/{id}

Returns a single *Country*.  Gets a country. A country or territory, identifiable by an ISO 3166 country code.

Reference: https://docs.bigcommerce.com/developer/api-reference/rest/admin/management/geography/countries/get-country

## Request

### Path parameters

- `id` (integer, required) — The ID of the country.
- `store_hash` (string, required) — Permanent ID of the BigCommerce store.

### Headers

- `Accept` (string, required, default: application/json) — The MIME type of the response body that the client accepts. Typically `application/json`.

## Response

### 200

The requested country.

- `country` (string, optional) — Country name.
- `country_iso2` (string, optional) — 2-letter country code.
- `country_iso3` (string, optional) — 3-letter country code.
- `id` (integer, optional) — Id of the country.
- `states` (countriesStates_Full, optional) — Refers to the `states` object return in `GET` countries requests.

## Types

### countriesStates_Full

Refers to the `states` object return in `GET` countries requests.

- `url` (string, optional)
- `resource` (string, optional)
