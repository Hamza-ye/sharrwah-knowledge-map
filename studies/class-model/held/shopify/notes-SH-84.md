# SH-84: the Shopify mobile app's settings index, its repeats, placed by script

**What the batch is.** 137 entries of Shopify's `mobile-app-settings-index`: the nodes that recur on another screen of the app's settings search, their parent's index apart, and the bare layout nodes (no text, description or id). `method/held_mobile_repeats.py --cut` put each node's first occurrence in SH-80, SH-82 and SH-83, for agents, and these here.

**The rule.**
- **A repeat** takes its first occurrence's lines, the same capability, support, scope and terms, its reading naming that entry and line.
- **A bare layout node** names nothing, so it is `out`, as the POS batches and the Tinker script placed theirs.
