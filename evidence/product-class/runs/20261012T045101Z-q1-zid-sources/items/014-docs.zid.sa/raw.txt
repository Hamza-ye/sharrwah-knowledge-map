        ## **Authentication**

        If `username` and `password` are provided when creating a webhook, Zid
        will include a `Basic Authentication` header when sending webhook
        requests.


        The values are combined in the format:


        ```js

        username:password

        ```

        This string is then `Base64` encoded and sent in the Authorization
        header.


        Example


        If the webhook was created with:


        ```

        username = user

        password = secret

        ```

        The encoded value will be:


        ```js

        base64encode('user:secret') = dXNlcjpzZWNyZXQ=

        ```

        Zid will send webhook requests with the following header:


        ```js

        Authorization: Basic dXNlcjpzZWNyZXQ=

        ```

        This allows partners to verify that the webhook request is coming from
        Zid.
