# Page widgets

The page widgets feature of the REST Content API makes page layouts portable by dividing pages into **regions**, **layouts**, **dropzones**, and **widgets**.

![Diagram of conceptual relationships in the page widgets feature](/_fern-img/eb62571345d733f29c378f79077bb352da735984501b6845d59c9ec954ad1acd.webp)

The page widgets feature is an extension of the [widgets feature](/developer/api-reference/rest/admin/content/widgets). You can work with widget objects using either set of endpoints. For more about using page widgets, see the [Page widgets overview](/developer/docs/admin/widgets-and-scripts/page-widgets).
