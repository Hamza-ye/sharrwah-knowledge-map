# Settlements

## Docs

- [List Instant Settlements](https://docs.salla.dev/settlements/list.md): This endpoint lists all the instant settlements including details such as amount and status that are associated with the store.
- [Create Instant Settlement](https://docs.salla.dev/settlements/create.md): This endpoint allows you to temporarily withhold a specific amount of money for settlement from the Merchant's wallet.
- [Update Instant Settlement](https://docs.salla.dev/settlements/update.md): This endpoint allows you to update the status and the amount of a specific settlment by by passing the `id` as a path parameter.
- [Instant Settlement Details](https://docs.salla.dev/settlements/details.md): This endpoint allows you to fetch the details for a specific settlement by passing the `id` as a path parameter.
- [Delete Instant Settlement](https://docs.salla.dev/settlements/delete.md): This endpoint allows you to delete settlment by by passing the `id` as a path parameter.
