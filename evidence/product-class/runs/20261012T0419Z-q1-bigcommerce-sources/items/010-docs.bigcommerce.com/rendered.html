# Catalog - Products

> The Catalog API manages products, categories, brands, bulk pricing rules, and more. To learn more about catalog resources, see the [Catalog Overview](/developer/docs/admin/catalog-and-inventory).

Our Catalog products endpoints let you [create products](/developer/api-reference/rest/admin/catalog/products/create-product), perform [batch operations on existing products](/developer/api-reference/rest/admin/catalog/products/update-products) and work with [reviews](/developer/api-reference/rest/admin/catalog/products/reviews), [images](/developer/api-reference/rest/admin/catalog/products/images), and [videos](/developer/api-reference/rest/admin/catalog/products/videos). Note that after a product is created initially, you can manage the nuances of its variations using the [product modifier](/developer/api-reference/rest/admin/catalog/product-modifiers), [product variant](/developer/api-reference/rest/admin/catalog/product-variants), and [product variant options](/developer/api-reference/rest/admin/catalog/product-variant-options) endpoints.

Other core product endpoints focus on [bulk pricing](/developer/api-reference/rest/admin/catalog/products/bulk-pricing-rules), [complex rules](/developer/api-reference/rest/admin/catalog/products/complex-rules), [custom fields](/developer/api-reference/rest/admin/catalog/products/custom-fields), and [metafields](/developer/api-reference/rest/admin/catalog/products/metafields). Product variant objects also have [their own metafields](/developer/api-reference/rest/admin/catalog/product-variants/metafields). For [MSF-enabled](/developer/docs/admin/multi-storefront) stores, the product object also contains product [channel assignments](/developer/api-reference/rest/admin/catalog/products/channel-assignments) and [category assignments](/developer/api-reference/rest/admin/catalog/products/category-assignments); read more about [products in the MSF context](/developer/docs/admin/multi-storefront/api-guide#products).

The Catalog API also contains an endpoint to [get a catalog summary](/developer/api-reference/rest/admin/catalog/products/summary).

> To learn more about authenticating Catalog endpoints, locate the **Authentication** section at the top of each endpoint, then click **Show Details**.
