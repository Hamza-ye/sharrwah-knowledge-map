# Settings V3

Manage settings and configuration for BigCommerce hosted stores and headless storefronts.

| Resource                                                                                                   | Description                                                                        |

| [Analytics](/developer/api-reference/rest/admin/management/settings/analytics)                             | Identifies and updates Web analytics providers.                                    |

| [Inventory Notifications](/developer/api-reference/rest/admin/management/settings/inventory-notifications) | Identifies and updates inventory notifications.                                    |
| [Logo](/developer/api-reference/rest/admin/management/settings/logo)                                       | Identifies and updates logo settings.                                              |
| [Logo Image](/developer/api-reference/rest/admin/management/settings/logo-image)                           | Creates a logo image.                                                              |
| [Search Filters](/developer/api-reference/rest/admin/management/settings/search-filters)                   | Identifies and updates enabled filters, available filters, and contextual filters. |

| [Storefront Search](/developer/api-reference/rest/admin/management/settings/storefront-search)             | Identifies and updates storefront search settings.                                 |
| [Storefront Security](/developer/api-reference/rest/admin/management/settings/storefront-security)         | Identifies and updates storefront security settings.                               |
| [Storefront SEO](/developer/api-reference/rest/admin/management/settings/storefront-seo)                   | Identifies and updates storefront SEO settings.                                    |
| [Storefront Status](/developer/api-reference/rest/admin/management/settings/storefront-status)             | Identifies and updates storefront status.                                          |
| [Units of Measurement](/developer/api-reference/rest/admin/management/settings/units-of-measurement)       | Identifies and updates units of measurement settings.                              |
