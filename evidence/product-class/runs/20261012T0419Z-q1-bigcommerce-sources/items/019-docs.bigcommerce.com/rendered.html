# Widgets

Create and manage widget templates, widgets, regions, and placements.

## Subresources

### Widget templates

[Widget templates](/developer/api-reference/rest/admin/content/widgets/widget-template) are reusable Handlebars-enabled HTML templates that define the structure of the widget on a page.

### Widgets

[Widgets](/developer/api-reference/rest/admin/content/widgets/widget) are units of content placed on specific pages in a Stencil theme. Widgets consist of a widget configuration and a widget template UUID and render as part of the storefront’s HTML.

### Regions

[Regions](/developer/api-reference/rest/admin/content/widgets/regions) are specific locations in the Stencil theme template files where you can place a widget.

### Placements

[Placements](/developer/api-reference/rest/admin/content/widgets/placement) determine the region where you place widgets and in what order.
