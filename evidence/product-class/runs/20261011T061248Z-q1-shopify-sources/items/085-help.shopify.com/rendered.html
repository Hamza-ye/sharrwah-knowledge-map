# Shopify Collabs

<aside class="note note-app"><p><img src="https://cdn.shopify.com/app-store/listing_images/a48f805d99a4948755fcfd3bd15d1aec/icon/CPOi9_yUxoEDEAE=.png" alt="Collabs icon"> <a href="https://apps.shopify.com/collabs">Shopify Collabs</a>: Install Shopify Collabs from the Shopify App Store.</p>
</aside>

<aside class="note"><h4>Note</h4><p>Using this feature requires Shopify Network Intelligence to be enabled in your privacy settings. Learn more about <a href="/en/manual/privacy-and-security/privacy/customer-privacy-settings/privacy-settings#network-intelligence">Shopify Network Intelligence</a>.</p>
</aside>


Shopify Collabs helps businesses and creators connect using a marketplace-style app.

Businesses can connect with creators by sending direct invites, sharing instant commission offers through an open access program, or setting up an online store page to accept affiliate applications. Businesses can use Shopify Collabs to send gifts or discount codes, track affiliate sales, and send payments to their affiliates.

Creators that have a Collabs account can search for products to create commission links, or apply to specific affiliate programs run by different businesses that use Shopify Collabs.

<aside class="note"><h4>Note</h4><p>Collabs isn&#39;t accepting new creator signups at this time. If you&#39;re a creator that has existing brand partnerships, then you can still use the Collabs app or log in to the Collabs website to access your profile. Merchants can continue to <a href="/en/manual/promoting-marketing/collabs/merchants/recruiting-creators#direct-invite">send direct invites to creators</a>, and <a href="/en/manual/promoting-marketing/collabs/merchants/recruiting-creators#respond-to-applicants">creator applications</a> can still be accepted by merchants.</p>
</aside>
