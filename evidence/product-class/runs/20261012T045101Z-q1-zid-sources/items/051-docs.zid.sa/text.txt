      summary: OneSignal Store Settings
      deprecated: false
      description: >-
        Returns all OneSignal push-notification settings for the store where the
        partner app is installed.


        This endpoint is hard-scoped to the one_signal settings namespace. The
        namespace cannot be changed using query parameters or request body
        fields. No other store settings can be read through this endpoint.


        The target store is resolved from the OAuth access token. There is no
        store ID in the URL.


        <Accordion title="🔑Scopes" defaultOpen>
            
        `third_one_signal_write` - OneSignal Notifications
         
        </Accordion>



        :::note[]

        ## **Note**

        - This scope covers both reading and writing OneSignal settings.

        - Tokens issued before this scope was granted will receive 403 Forbidden
        until the store re-authorizes the app.


        **Behavior**

        - Returns all settings stored under the one_signal namespace for the
        store.

        - If the store does not have any OneSignal settings yet, the endpoint
        returns an empty payload array.

        :::



        :::info[]

        ## Important

        - This endpoint only reads settings under the one_signal namespace.

        - The namespace is fixed server-side and cannot be changed.

        - The store is resolved from the OAuth access token.

        No store ID is required in the URL.
