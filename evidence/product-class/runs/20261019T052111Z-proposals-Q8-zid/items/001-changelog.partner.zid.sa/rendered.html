Custom Email Notifications & Store Info in Token Expiry Alerts
We’d like to suggest two enhancements for the access token expiry notifications sent by the Zid platform: Custom Recipient Control: Please provide an option to customize the recipient email address for access token expiry alerts per app. This would allow relevant team members to receive the notifications directly (e.g. technical or support contacts) and avoid relying solely on the account's default email. Additional Store Context in Email: Currently, the token expiry email includes only the Store ID. We recommend adding: Store name Store URL This will help partners quickly identify which client/store the alert refers to without having to look up the Store ID manually.
