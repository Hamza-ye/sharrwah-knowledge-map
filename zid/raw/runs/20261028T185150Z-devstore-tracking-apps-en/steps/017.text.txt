Overview
Google Tag Manager app lets you add a Google Tag Manager (GTM) container without needing to manually edit your store’s code.
Key points merchants should pay attention to when adding Google Tag Manager:
- Get the Container ID: Make sure you create a GTM account and copy your GTM-XXXXXX Container ID before installation.. - Set up events in GTM: After installing the Pixel, you should: - Add triggers for key events (e.g., Page View, AddToCart, Purchase). - Link variables to the data available from Zid (e.g., value, items). - Test before publishing: - Use GTM Preview Mode + tools like Google Tag Assistant to test
To track Snapchat Pixel events or TikTok conversions, we strongly recommend enabling their official apps (e.g., Snapchat Ads app or the official TikTok Pixel app on Zid) instead of relying only on Google Tag Manager.
This ensures better performance, more accurate tracking, and deeper integration with advertising platforms.
