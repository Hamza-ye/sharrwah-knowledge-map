# Transactions API (Beta)

The Transactions API lets you create transaction records in BigCommerce for payments that were processed externally. This enables merchants to use BigCommerce for post-order actions such as capture, void, and refund on transactions that originated outside of BigCommerce.

For supported providers, payment methods, and detailed usage instructions, see the [Transactions API guide](/developer/docs/admin/checkout-and-cart/payments/transactions-api).
