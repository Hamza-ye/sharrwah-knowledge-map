# Carts

Create and manage server-side carts using BigCommerce cart logic. Use these endpoints to create carts, add and update line items, generate cart redirect URLs, and manage cart-level metafields and settings.

For storefront cart operations, see the [Storefront Carts API](/developer/api-reference/rest/storefront/carts). To learn more about cart and checkout flows, see the [Orders Guide](/developer/docs/admin/checkout-and-cart/orders).
