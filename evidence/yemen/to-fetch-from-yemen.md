# To fetch from inside Yemen

Sources this repository needs but could not fetch from outside Yemen. Open each address from inside Yemen without a VPN. Save the result exactly as received, into a founder run as `evidence/yemen/README.md` describes: the file as downloaded, or for a web page an `.mhtml` copy plus a full-page screenshot, and a one-line entry in `sources.tsv`. Tick the box when done.

Where a page is an index, such as a list of decisions or circulars, save the index first. Then save the documents the note names.

Items are ranked within each section. Section 1 matters most.

**Status, 10 October 2026.** The founder saved 15 of these pages from inside Yemen into `blocked-evidence-founder/`; they are ticked below, with their file id. The founder reports that the other addresses could not be opened from inside Yemen either.
