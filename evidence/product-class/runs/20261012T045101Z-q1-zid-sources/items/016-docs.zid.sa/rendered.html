        </Accordion>



        :::info[]

        ## Note

        Customer Wallet APIs are available only for stores using one of the
        following currencies: `SAR`, `AED`, `QAR`, `KWD`, `BHD`, or `OMR`. 

        Stores using any other currency receive the message: `Customer wallets
        is only available for GCC countries.`


        :::


        :::warning[]

        ## Note

        This API requires prior approval before use. Only approved use cases are
        allowed to access `Customer Wallet write` operations. Approval is
        reviewed as part of the `app review` process.


        :::



        :::note[]

        ## Note

        Provide exactly one of `cashback_amount `or `cashback_percentage`.
        Providing both fields or neither field causes the request to fail.
