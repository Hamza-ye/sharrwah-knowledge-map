# SH-81: the Shopify mobile app's navigation, its repeats, placed by script

**What the batch is.** 58 entries of Shopify's `mobile-app-navigation`: the nodes that recur on another screen of the app, or at another place of the same screen, their parent's index apart, and the bare layout nodes (no text, description or id). `method/held_mobile_repeats.py --cut` put each node's first occurrence in SH-80, for an agent, and these here.

**The rule.**
- **A repeat** takes its first occurrence's lines in SH-80, the same capability, support, scope and terms, its reading naming that entry and line.
- **A bare layout node** names nothing, so it is `out`, as the POS batches and the Tinker script placed theirs.

## The coordinator's check (31 October 2026, the script's batch)

- **The repeats are exact:** a node is the same where its entry's text is the same apart from its parent's index, so every repeat states what its first occurrence states.
- **Cost:** the script, no agent.
