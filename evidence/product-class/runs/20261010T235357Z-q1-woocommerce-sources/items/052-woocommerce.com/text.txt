Can I use my existing Stripe account with WooPayments?

No, it is not possible to use an existing Stripe account with WooPayments.

Although WooPayments is built in partnership with Stripe, our plugin uses a special type of Stripe account (called a “Stripe Express” account). The Express account is created when you sign up for WooPayments.

If you are logged into Stripe.com with an existing Stripe account when you start the WooPayments signup process, your new Stripe Express account can be linked with an existing Stripe account. However, they will still be two separate accounts that do not share or sync data in any way.

If you must use an existing Stripe account on your WooCommerce store, please use the free Stripe extension. If you are unsure whether to use WooPayments or the Stripe extension, consult our comparison page.
