# Uploading and managing files

<aside class="note note-caution"><h4>Caution</h4><p>You should only ever upload files to the <strong>Content</strong> &gt; <strong>Files</strong> section of your Shopify admin when they&#39;re intended for public access on your store, such as product media, downloadable content, and other storefront images. Never upload any documents that contain confidential, personal, or sensitive information about you, your business, or your customers.</p>
</aside>


The **Files** section is where you can manage all files uploaded to your store, including images, videos, 3D models, and other file types, such as PDFs and CSV files. You can upload, manage, and delete files from the [**Files**](https://admin.shopify.com/content/files) section in your Shopify admin.

The file picker is available in different areas of your Shopify admin, such as the following examples:

* Adding media to a [product](/manual/products/product-media/add-media).
* Editing your [theme](/manual/online-store/images/theme-images).
* Creating [metafields](/manual/custom-data/metafields).
* Adding media in the [rich text editor](/manual/shopify-admin/productivity-tools/rich-text-editor).

All files you upload through the file picker are added to the [**Files**](https://admin.shopify.com/content/files) page of your Shopify admin.

### File format requirements

If you're on a paid plan, then you can upload any file format other than HTML.

If you're on a trial plan, then you can upload only the following file formats:

* JS
* CSS
* GIF
* JPEG
* PNG
* JSON
* CSV
* PDF
* WebP
* HEIC

You also need to [verify your email address](/manual/privacy-and-security/account-security/verify-account-email) before you can upload PDF files.

If you're on a trial plan and you want to upload other file formats, then [check and update your plan](/manual/your-account/manage-billing/managing-your-bills/billing-plan-changes#change-plan).

Different parts of your store, such as your theme, pages, and blogs, only support certain file formats. For more information about supported file formats, refer to the following resources:

* [Using the rich text editor](/manual/shopify-admin/productivity-tools/rich-text-editor): for pages, blog posts, product and collection descriptions, and theme elements
* [Uploading media](/manual/online-store/images/theme-images#image-formats): for images and videos in your theme

<aside class="note note-information"><h4>Tip</h4><p>If you want to share a video that&#39;s larger than 1GB or longer than 10 minutes, then you can use a video hosting service such as <a href="https://www.youtube.com/">YouTube</a> or <a href="https://vimeo.com/">Vimeo</a>, and then add the video&#39;s sharing link to your content.</p>
</aside>

<aside class="note"><h4>Note</h4><p>You can import <a href="/en/manual/products/import-export">products</a>, <a href="/en/manual/customers/import-export-customers">customers</a>, or <a href="/en/manual/inventory-and-locations/setup/inventory-csv">inventory data</a> using <a href="/en/manual/shopify-admin/productivity-tools/csv-files#csv-files">CSV files</a>. Importing data by CSV file isn&#39;t done through the <strong>Files</strong> page, but through the respective page in your Shopify admin.</p>
</aside>

## Search and filter the file list {#filter-the-file-list}

You can filter the file list or search for a file from the **Content** > **Files** page of your Shopify admin or in the **File** picker.

You can filter your files in the following ways:

* Search file attributes, including file names and types, using the search bar.
* Filter by size using the **File size** range selector.
* Filter by type using the **File type** menu.
* Filter by file reference using the **Used in** menu.
* Filter by alt text using the **Alt text** menu.

All filters display in-line in the search bar, so you get a full view of the criteria influencing your search results. You can also use `is`/`is not` and `or`/`and` logical operators to create more advanced views with specific filter criteria.

<aside class="note note-information"><h4>Tip</h4><p>If you need to perform the same searches or filter by the same terms regularly, then you can <a href="/en/manual/shopify-admin/productivity-tools/file-uploads#save-filters">save the filter view</a>.</p>
</aside>

Learn more about [searching, filtering, and sorting your list views in the Shopify admin](/manual/shopify-admin/productivity-tools/searching-filtering-views).

#### Steps:

1. From your Shopify admin, go to **Content** > [**Files**](https://admin.shopify.com/content/files).

2. Optional: Click **All** to open the view menu, and then select the view that you want to filter.
3. Select an operator and value for your filter. The available values are different depending on the filter that you select.
4. Optional: Continue typing keywords to continue adding different filters and values to refine your search:
     - To include an additional filter with an `and` operator to your search, click <img src="https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/PlusCircleIcon.svg" alt="Plus Circle Icon" class="admin-icon" /> or add a space, and then start typing the name of the additional filter that you want to include.
     - To include an additional value with an `or` operator to a filter, add a comma, and then start typing the name of the additional value that you want to include.
5. Optional: Click the filter tags of any filter in the search bar to edit the filter.

### Edit columns in your Files list {#edit-columns}

You can edit columns in both default and custom views, and the changes that you make apply only to the view that you're currently on. You can hide or unhide columns, as well as reorder the columns, with the exception of the main leftmost column.

#### Steps:

1. From your Shopify admin, go to **Content** > [**Files**](https://admin.shopify.com/content/files).

2. Optional: Click **All** to open the view menu, and then select the custom view that you want to edit the columns for.
3. Click the <img src="https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/LayoutColumns3Icon.svg" alt="Layout Columns 3" class="admin-icon" /> icon to open the display option panel.
4. In the **Columns** section, customize your view's columns by doing any of the following actions:
      - To hide a column, click <img src="https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/ViewIcon.svg" alt="View" class="admin-icon" />.
      - To unhide a column, click <img src="https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/HideIcon.svg" alt="Hide" class="admin-icon" />.
      - To rearrange a column, click <img src="https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/DragHandleIcon.svg" alt="Drag handle" class="admin-icon" /> and drag the column up or down.
5. Optional: To permanently apply the column order to your custom view, click **Save** > **Update view**.

### Use bulk action to delete multiple files {#use-bulk-action-with-a-filter}

In any file view, you can select some or all of the files and delete them in bulk. You can switch between file views to continue selecting files, and apply filters or search using keywords to display only relevant files that you can also select.

<aside class="note"><h4>Note</h4><p>If you&#39;re on a desktop device, then you can click <strong>Show all selected</strong> to display only the files that you&#39;ve currently selected.</p>
</aside>

Learn more about [using bulk actions in your Shopify admin](/manual/shopify-admin/productivity-tools/bulk-actions).

#### Steps:

1. From your Shopify admin, go to **Content** > [**Files**](https://admin.shopify.com/content/files).

2. Click a file view.
3. [Select the items that you want to delete](/manual/shopify-admin/productivity-tools/bulk-actions#select-items-to-edit-in-bulk).
4. Click **Delete files**.
5. In the dialog, click **Delete**.

## Replace files

You can replace a file from the **Files** page. You can't replace files as a bulk action.

<aside class="note"><h4>Note</h4><p>When you replace a file, the file name stays the same, but the file&#39;s link changes.</p>
</aside>

#### Steps:

1. From your Shopify admin, go to **Content** > [**Files**](https://admin.shopify.com/content/files).

2. Click the **Replace** icon next to the file name.
3. Select the file that you want to upload.

## Edit files without overwriting the existing file

In the file editor, it's possible to make destructive edits to an image, such as changing the background of an image. To make changes without overwriting an existing file, save the changes as new.

#### Steps:

1. From your Shopify admin, go to **Content** > [**Files**](https://admin.shopify.com/content/files).

2. Select a media file to open the file editor.
3. Make file edits.
4. From the Save dropdown menu, select Save as new.

Saving as new saves the new file to your store's file system and preserves the original image in its original state.

## Best practices for file names

When you upload an image file, a unique identifier might be added to the filename. This can happen in the following situations:

* A file with the same name already exists in your store. This includes files uploaded directly to product pages that might not appear in **Content** > **Files**.
* The filename contains special characters or formatting that conflicts with Shopify's Content Delivery Network (CDN).

To prevent unique identifiers from being added to filenames, use the following file naming practices:

* Ensure the filename is unique and doesn't match any existing files in your store.
* Avoid using underscores immediately before image dimensions in the filename. For example, use `product-image-5x4.jpeg` instead of `product_image_5x4.jpeg`.
* Use descriptive filenames that don't include special formatting.

If you need to change a filename after upload, then you can rename files from the **Content** > [**Files**](https://admin.shopify.com/content/files) page by editing the **URL Handle**.

## Generate image

You can generate images using AI directly in the unified file picker throughout the Shopify admin. This feature lets you create custom images for your products, content, and marketing materials without needing external tools.

When you generate an image, it's created temporarily and displayed in the file picker. To save the generated image to your store, you need to click **Keep**. If you don't explicitly save the image by clicking **Keep**, then the generated image will be discarded and won't be saved to your store.

<aside class="note"><h4>Note</h4><p>Generated images that aren&#39;t saved by clicking <strong>Keep</strong> are automatically discarded and don&#39;t count toward your storage limits.</p>
</aside>
