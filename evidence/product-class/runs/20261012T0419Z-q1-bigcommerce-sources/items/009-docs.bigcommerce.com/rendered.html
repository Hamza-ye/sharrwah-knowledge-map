# Catalog - Category trees

> The Catalog API manages products, categories, brands, bulk pricing rules, and more. To learn more about catalog resources, see the [Catalog overview](/developer/docs/admin/catalog-and-inventory).

Our Catalog category trees and their [categories](/developer/api-reference/rest/admin/catalog/category-trees/categories) endpoints are the more modern and performant counterparts to the [categories (deprecated)](/developer/api-reference/rest/admin/catalog/categories) endpoints. Although the category trees endpoints and objects are designed to center an MSF-compatible, [multi-tenant category tree architecture](/developer/docs/admin/multi-storefront/api-guide#categories), the endpoints work just as well in a single storefront context and support batch requests. Use [catalog trees categories](/developer/api-reference/rest/admin/catalog/category-trees/categories) endpoints, instead of [categories (deprecated)](/developer/api-reference/rest/admin/catalog/categories) endpoints.

The category trees endpoints let you [get the categories for a specific tree](/developer/api-reference/rest/admin/catalog/category-trees/get-category-tree), and [bulk create](/developer/api-reference/rest/admin/catalog/category-trees/categories/create-categories), [bulk update](/developer/api-reference/rest/admin/catalog/category-trees/categories/update-categories), and [bulk delete](/developer/api-reference/rest/admin/catalog/category-trees/categories/delete-tree-categories) categories. You can also [bulk update the properties of category trees](/developer/api-reference/rest/admin/catalog/category-trees/upsert-category-trees), which includes changing the channels to which a tree is assigned.

The terms "category tree" and "catalog tree" are used interchangeably throughout the documentation.

> To learn more about authenticating Catalog endpoints, locate the **Authentication** section at the top of each endpoint, then click **Show Details**.
