# Get Storefront Status

GET https://api.bigcommerce.com/stores/{store_hash}/v3/settings/storefront/status

Returns storefront status-related settings. 

 - Channel ID can be used as a query parameter for getting channel-specific settings. If omitted, you will interact with the global settings only. 

 - `null` indicates that a particular field has not been overridden on a channel level when channel level settings are requested and values are inherited from global level.

Reference: https://docs.bigcommerce.com/developer/api-reference/rest/admin/management/settings/storefront-status/get-settings-storefront-status

## Request

### Path parameters

- `store_hash` (string, required) — Permanent ID of the BigCommerce store.

### Query parameters

- `channel_id` (integer, optional) — Channel ID to use for channel-specific settings. If omitted, you will interact with the global settings only.

### Headers

- `Accept` (string, required, default: application/json) — The [MIME type](https://developer.mozilla.org/en-US/docs/Web/HTTP/Basics_of_HTTP/MIME_types) of the response body.

## Response

### 200

OK, null indicates that a particular field has not been overridden on a channel level when channel level settings are requested

- `data` (StorefrontStatus, optional)
- `meta` (MetaOpen, optional) — Response metadata.

## Types

### StorefrontStatus

- `down_for_maintenance_message` (string, optional)
- `prelaunch_message` (string, optional)
- `prelaunch_password` (string, optional) — A read-only value representing the auto-generated storefront password.

### MetaOpen

Response metadata.
