# Getting started with Shopify B2B

Before you start using Shopify B2B, you need to decide whether to create a blended store for both B2B and D2C customers and orders, or a dedicated B2B-only store.

Before you set up your store, you need to review considerations for using Shopify B2B. You can also get familiar with the available B2B features on Shopify.

After you set up your store, consider testing the customer experience using a test customer before inviting your customers to login and place orders.
