# Channels

Create and manage sales [channels](/developer/docs/integrations/channels), their [sites](/developer/api-reference/rest/admin/management/channels/site), and their [product listings](/developer/api-reference/rest/admin/management/channels/listings).

## Channels

A [channel](/developer/api-reference/rest/admin/management/channels) is anywhere a merchant sells their products. This encompasses headless storefronts, marketplaces, POS systems, and marketing platforms.

### Status

Allowed values for a channel's `status` vary by channel `type`.

| Type                              | Writable Statuses                                        |
| :-------------------------------- | :------------------------------------------------------- |
| `storefront`                      | `prelaunch`, `active`, `inactive`, `archived`, `deleted` |
| `marketing`, `marketplace`, `pos` | `connected`, `disconnected`, `archived`, `deleted`       |

> **Note**
>
> * You can restore a Channel with `deleted` status within **90 days** after deletion by contacting the BigCommerce support team. After the 90-days grace period is over, the Channel `status` will become `terminated`.
> * The `terminated` status is read-only. Channels with a `status` of `terminated` **cannot** be restored.

## Channel listings

[Channel listings](/developer/api-reference/rest/admin/management/channels/listings) allow you to manage catalog differences among different storefronts or marketplaces.

## Channel site

A [Channel site](/developer/api-reference/rest/admin/management/channels/site) refers to the domain associated with a channel.

> **Note**
>
> For the "urls" object, we no longer modify the `www` prefix of the primary URL. The API returns URLs exactly as the customer enters them, similar to the "url" field.
>
> * If the customer saves a URL with `www`, the API returns it with `www`.
> * If the customer saves a URL without `www`, the API returns it without `www`.
